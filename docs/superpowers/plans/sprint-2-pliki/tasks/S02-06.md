# S02-06 — Resolving the enemy turn

File to edit: src/core/combat/enemy-turn.ts

Goal: apply the enemy's chosen actions to the player (circles, hand, hp) and the enemy (block, stolen cards) and report what happened as a log. Pure function: the reducer calls it at the end of every player turn.

Signatures (do not change): the types `CircleCreature`, `PlayerState`, `BossState`, `EnemyAction`, `EnemyTurnResult` and `resolveEnemyTurn(player, boss, actions)` in the stub. Parameter names in the stub start with an underscore only because the stub does not use them; use normal names.

`resolveEnemyTurn(player, boss, actions)` applies `actions` in order and returns the new `player`, the new `boss` and a `log` (array of strings). Never modify the inputs (nested arrays and creature objects included).

Actions:
- `{ type: 'atak', amount, direct? }` — one hit.
  - Target, when `direct` is not `true`: the creature with the highest `attack` among the circles (on a tie the lowest circle index). If all circles are empty the target is the player.
  - Target, when `direct === true`: always the player, whatever stands in the circles.
  - Hitting a creature: it loses `min(amount, health)` health; log `trafienie krag<i> <lost>` (i = circle index). If its health reaches 0 the circle becomes `null` and you log `zniszczono krag<i>`. Excess damage is lost. Player block does not protect creatures.
  - Hitting the player: block absorbs first (block goes down), then hp goes down by the rest, not below 0. Log `trafienie gracz <hpLost>` where `hpLost` is the hp actually lost (can be 0).
- `{ type: 'wielokrotny', amount, times, direct? }` — perform `atak` with `amount` and `direct` `times` times; the target is chosen again before every hit.
- `{ type: 'tarcza', amount }` — the boss gains `amount` block; log `tarcza <amount>`.
- `{ type: 'klatwa', circle }` — if that circle holds a creature it becomes `null` and you log `zniszczono krag<circle>`. Then, always, add the card id `'klatwa'` to the end of the player's discard pile, increase `player.curses` by 1 and log `klatwa krag<circle>`.
- `{ type: 'kradziez' }` — if the hand is not empty remove its last card, append it to `boss.stolen` and log `kradziez <card>`; otherwise log `kradziez brak`.

Defeat: as soon as the player's hp reaches 0 log `porazka` and stop; the remaining hits and actions are not applied.

The log entries are exactly the strings above, e.g. `trafienie krag2 4`, `zniszczono krag2`, `trafienie gracz 3`, `tarcza 8`, `klatwa krag0`, `kradziez ziemia-jelen-spryt`, `porazka`. The result must not depend on the order of the properties of the inputs.

Rules: no Math.random, no Date.now, no new dependencies, no Node APIs, `import type` for types.

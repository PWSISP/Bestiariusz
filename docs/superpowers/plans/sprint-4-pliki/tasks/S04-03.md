# S04-03 — Layers of a creature picture

File to edit: src/view/creature-layers.ts

Goal: every one of the 150 creatures is drawn from three layers: the background of its element, the silhouette of its form (tinted with the element's colour) and the mark of its trait in a corner. This module computes where each layer goes in a picture box of a given size; the renderer draws what it returns. It uses the tables and helpers of `src/view/art-style.ts` (read that file first).

Signatures (do not change): `LayerRole`, `LayerPlan` and `planCreatureLayers(spec, box)` in the stub. `CreatureSpec` is `{ element, form, trait }` (three symbol ids), `Size` is `{ width, height }`.

Rules (`box` is the picture box, the layers are placed inside it; units are the units of the box):
1. `box.width` and `box.height` must both be finite numbers greater than 0, otherwise throw a `RangeError`.
2. Return exactly three plans in this order: `background`, `silhouette`, `overlay`.
3. background: `textureId` = `backgroundTextureId(spec.element)`, `x` 0, `y` 0, `width` = `box.width`, `height` = `box.height`, `tint` null, `alpha` 1.
4. silhouette: `style = formStyle(spec.form)`. Start with `height = box.height * style.scale` and `width = height * style.aspect`. When `width` is larger than `box.width * 0.9`, set `width = box.width * 0.9` and `height = width / style.aspect`. Then `x = (box.width - width) / 2` and `y = (box.height - height) / 2 + style.dy * box.height`. `textureId` = `silhouetteTextureId(spec.form)`, `tint` = `elementColor(spec.element)`, `alpha` 1.
5. overlay: `side = min(box.width, box.height)`, `size = side * 0.3`, `margin = side * 0.05`, both `width` and `height` equal `size`. The corner is `traitCorner(spec.trait)`: `tl` → `x = margin`, `y = margin`; `tr` → `x = box.width - size - margin`, `y = margin`; `bl` → `x = margin`, `y = box.height - size - margin`; `br` → `x = box.width - size - margin`, `y = box.height - size - margin`. `textureId` = `overlayTextureId(spec.trait)`, `tint` null, `alpha` 0.9.
6. Symbol ids that the art tables do not know are not an error: the helpers of `art-style.ts` return defaults, use them.
7. Never modify the arguments.

Edge cases (box 100 wide, 140 high):
- sowa: silhouette width 69.3, height 77, x 15.35, y 31.5.
- wilk: the silhouette is 108.5 wide before the limit, so it becomes 90 wide, 72 high, x 5, y 41.
- a very wide box (width 1000, height 100): the 0.9 limit does not apply, the silhouette keeps its aspect.

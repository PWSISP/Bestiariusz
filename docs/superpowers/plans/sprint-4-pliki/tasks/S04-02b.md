# S04-02b — Touch input of the hand: select, drag, play

File to edit: src/view/hand-input.ts

Goal: the player picks a card from the hand by tapping it, or drags it to a circle (creature) or above the cast line (spell). This module is the state machine behind that: it receives pointer events and says what state the hand is in and what, if anything, the game must do. The combat screen turns the intents into game actions.

Signatures (do not change): `DRAG_THRESHOLD`, `IDLE`, all types, and `reduceHandInput(state, event, ctx)` in the stub. `Rect` comes from `src/view/geometry.ts`.

Rules. `current` is the state, except that a state which has a `handIndex` outside `0 … ctx.hand.length - 1` counts as `IDLE` (and the returned state is then `IDLE` unless a rule below says otherwise). "Ignored" means: return `current` and the intent `{ type: 'none' }`. A point is "inside" a circle when `rect.x <= x < rect.x + rect.width` and `rect.y <= y < rect.y + rect.height`. "Free" means `ctx.freeCircles[i] === true`.

1. `reset` (any state) → `IDLE`, intent none.
2. `pointerDown`:
   - in `pressing` or `dragging`: ignored (only one finger counts).
   - `handIndex` not an integer in `0 … ctx.hand.length - 1`: ignored.
   - otherwise → `pressing` with `handIndex`, `startX`, `startY` from the event, and `wasSelected` true only when the state was `selected` with the same `handIndex`. Intent none.
3. `pointerMove`:
   - in `dragging`: stay in `dragging` with the new `x`, `y` and recomputed `overCircle` / `overCast` (rule 7).
   - in `pressing`: when the distance (`Math.hypot`) between the event and the start point is below `DRAG_THRESHOLD`, or the card is not playable (`ctx.hand[handIndex].playable` false): ignored. Otherwise → `dragging` for the same `handIndex` (rule 7).
   - in other states: ignored.
4. `pointerUp`:
   - in `pressing` (a tap), card info `info = ctx.hand[handIndex]`:
     - `wasSelected` false → `selected` with `handIndex`, intent none (any card can be selected, also a curse or a card without Ember).
     - `wasSelected` true and `info.kind` is not `'spell'` → `IDLE`, intent none (selection cancelled).
     - `wasSelected` true, a spell that is playable → `IDLE`, intent `{ type: 'play', handIndex }` (no `circle` property).
     - `wasSelected` true, a spell that is not playable → state `selected` with `handIndex`, intent `{ type: 'refuse', handIndex, reason }` where `reason` is `info.blocked`, or `'unplayable'` when that is null.
   - in `dragging`: the position of the event (not the last move) decides, and the state becomes `IDLE`. A spell: `event.y < ctx.castLineY` → intent `{ type: 'play', handIndex }`, otherwise none. A creature: the circle under the event point (first inside, free or not): none → intent none; a free one → `{ type: 'play', handIndex, circle }`; an occupied one → `{ type: 'refuse', handIndex, reason: 'circle_occupied' }`.
   - in other states: ignored.
5. `pointerCancel`: `pressing` or `dragging` → `IDLE`, intent none; other states ignored.
6. `tapCircle` (a tap on circle `circle`): only in `selected`, otherwise ignored; a `circle` that is not an integer from 0 to 2 is ignored. With `info = ctx.hand[handIndex]`:
   - `info.kind` is not `'creature'` → ignored.
   - not playable → stay `selected`, intent `{ type: 'refuse', handIndex, reason }` (`info.blocked`, or `'unplayable'` when null).
   - the circle is free → `IDLE`, intent `{ type: 'play', handIndex, circle }`.
   - the circle is not free → stay `selected`, intent `{ type: 'refuse', handIndex, reason: 'circle_occupied' }`.
7. `dragging` fields: `overCircle` is the index of the circle under the point when the card is a creature and that circle is free, otherwise null (a spell or a curse never has one). `overCast` is true only for a spell with `y < ctx.castLineY`.
8. `tapOutside`: `selected` → `IDLE`, intent none; other states ignored.
9. Never modify the arguments.

Edge cases:
- press at (100, 600), move to (107, 600): still `pressing`; move to (108, 600): `dragging`.
- a creature released exactly on the lower edge of a circle (`y === rect.y + rect.height`) is not inside it.
- a spell released at `y === ctx.castLineY` is not cast.
- a card that cannot be played cannot be dragged, but tapping it selects it.

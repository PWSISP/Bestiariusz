# S03-06 — Counting creatures for synergy effects

File to edit: src/core/combat/synergy.ts

Goal: an effect of a creature can depend on the other creatures in the circles ("for every other thunder creature"). This module answers one question: how many creatures does the effect count? The effect system (S03-05) multiplies the effect's `amount` by that count. The three circles are the only board that exists.

Signatures (do not change): the `BoardCreature` interface, `countScope(scope, circles, index)` and `scaledAmount(effect, circles, index)` in the stub. Parameter names in the stub start with an underscore only because the stub does not use them; use normal names. `EffectScope` and `CreatureEffectDef` come from `src/core/types.ts` (import type).

`countScope(scope, circles, index)` counts, from the point of view of the creature in circle `index`:
- `self`: always `1`.
- `sameElementOthers`: the other creatures whose `element` equals the element of the creature at `index`.
- `sameElementAll`: the same, plus the creature itself.
- `othersAny`: every other creature, whatever its element.

Wind is not a wildcard here: only an identical `element` id counts as the same element.

`scaledAmount(effect, circles, index)` returns `effect.amount * countScope(effect.scope, circles, index)`; it is `0` when nothing is counted.

Errors: both functions throw `RangeError` when `circles` does not have exactly 3 entries, when `index` is not an integer, when `index` is outside `0..2`, or when circle `index` is empty (`null`). An unknown `scope` also throws `RangeError`. Empty circles (`null`) are never counted.

Never modify the arguments.

Rules: no Math.random, no Date.now, no new dependencies, no Node APIs, `import type` for types.

Edge cases:
- `sameElementOthers` with no other creature of that element → `0`, and so `scaledAmount` → `0`
- `othersAny` with two other creatures of different elements → `2`
- `index` `3`, `-1`, `1.5` and `NaN` → `RangeError`

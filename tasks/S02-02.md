# S02-02 — Applying damage

File to edit: src/core/combat/damage.ts

Goal: one function that applies a hit to a combatant (the enemy). The combat reducer uses it for spells, creature attacks and rituals.

Signatures (do not change): the types `Combatant`, `Hit`, `DamageResult` and `applyDamage(target: Combatant, hit: Hit): DamageResult` in the stub. Parameter names in the stub start with an underscore only because the stub does not use them; use normal names.

Steps of `applyDamage`, in this order:
1. If `hit.amount <= 0`, nothing happens: return a copy of the target with `blocked = 0`, `dealt = 0`, `overkill = 0`, `killed = false`.
2. Element modifier, only when `hit.element` is not `null`:
   - element in `target.resist` and not in `target.weak`: `amount = Math.floor(amount * 0.5)`;
   - element in `target.weak` and not in `target.resist`: `amount = Math.floor(amount * 1.5)`;
   - in both lists or in neither: unchanged.
3. Block: unless `hit.pierce === true`, block absorbs first: `blocked = min(target.block, amount)`; the target's block and `amount` go down by `blocked`. With `pierce`, block is ignored and unchanged (`blocked = 0`).
4. Health: `dealt = min(amount, target.hp)`; hp goes down by `dealt`; `overkill = amount - dealt`.
5. `killed` is `true` only if the target had hp > 0 before the hit and has hp 0 after it.

Return a new `target` object. Never modify the input objects or their arrays.

Rules: no Math.random, no Date.now, no new dependencies, no Node APIs, `import type` for types.
Tests: tests/S02-02.test.ts (do not edit).
Done when: vitest, tsc and eslint pass with no errors.

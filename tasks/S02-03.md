# S02-03 — Deck, hand and discard pile

File to edit: src/core/combat/deck.ts

Goal: the card piles of one combat. Shuffling uses the injected `Rng` (src/core/rng.ts) so that a seed fully decides the combat.

Signatures (do not change): `HAND_LIMIT` (= 5), `DeckState`, `createDeck`, `drawCards`, `endTurn` in the stub. Parameter names in the stub start with an underscore only because the stub does not use them; use normal names.

`createDeck(cards, rng)`: returns `{ draw: rng.shuffle(cards), hand: [], discard: [] }`. Exactly one `rng.shuffle` call, no other RNG method. Does not modify `cards`.

`drawCards(state, n, rng)`: draw `n` cards one at a time. For each card:
1. If the draw pile is empty: if the discard pile is also empty, stop drawing; otherwise the draw pile becomes `rng.shuffle(discard)` and the discard pile becomes empty.
2. Take the top card (index 0) of the draw pile.
3. If the hand already holds `HAND_LIMIT` cards, the card goes to the end of the discard pile ("burned"). Otherwise it is appended to the hand.
Call `rng.shuffle` exactly once per reshuffle and no other RNG method. Do not shuffle when it is not needed (n <= 0, or the draw pile still has cards). `n <= 0` returns a copy of the state unchanged. Never modify the input state or its arrays.

`endTurn(state)`: every card of the hand goes to the end of the discard pile, keeping order. The draw pile is unchanged. Never modify the input.

Rules: no Math.random, no Date.now, no new dependencies, no Node APIs, `import type` for types.

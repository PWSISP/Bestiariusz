# S01-02 — Clamp a number to a range

File to edit: src/core/math.ts

Goal: `clamp` limits a number to the closed range [min, max]. The game uses it for health, Żar (ember points) and damage, so invalid input must fail loudly instead of producing NaN.

Signatures (do not change):
- `export function clamp(value: number, min: number, max: number): number`

Rules:
- Return `min` when `value < min`, `max` when `value > max`, otherwise `value`.
- Throw `RangeError` when `min > max` or when any argument is `NaN`.
- Infinite values are valid: `Infinity` clamps to `max`, `-Infinity` clamps to `min`.
- No Math.random, no Date.now, no new dependencies, no Node APIs, `import type` for types.

Edge cases:
- `clamp(5, 0, 3)` → `3`
- `clamp(-1, 0, 3)` → `0`
- `clamp(2, 0, 3)` → `2`
- `clamp(1, 1, 1)` → `1`
- `clamp(Infinity, 0, 3)` → `3`
- `clamp(-Infinity, 0, 3)` → `0`
- `clamp(1, 3, 0)` → `RangeError`
- `NaN` as `value`, `min` or `max` → `RangeError`

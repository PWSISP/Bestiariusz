# S02-05 — Enemy intent selection

File to edit: src/core/combat/intent.ts

Goal: every turn the enemy picks one action, shown to the player in advance as its "intent". The choice is a pure function of the situation (no randomness), so combats stay reproducible.

Signatures (do not change): the types `ConditionKind`, `Condition`, `BossAction`, `IntentContext` and `chooseIntent(actions: readonly BossAction[], ctx: IntentContext): string` in the stub. Parameter names in the stub start with an underscore only because the stub does not use them; use normal names.

`chooseIntent` returns the `id` of the chosen action:
1. `actions` empty: throw an `Error`.
2. Score of an action = `baseWeight` + the `bonus` of every condition that holds:
   - `'playerHandAtMost'`: `ctx.playerHand <= value`;
   - `'bossHpBelowPct'`: `ctx.bossHp / ctx.bossMaxHp * 100 < value` (strictly less);
   - `'playerCirclesAtLeast'`: `ctx.playerCircles >= value`.
3. Exclusions. `ctx.history` lists the ids of earlier actions, oldest first (the last element is the previous turn). An action is excluded when:
   - it has a `cooldown` `c > 0` and its id appears among the last `c` entries of `history`; or
   - the last two entries of `history` are both this action's id (no action three times in a row).
4. Among the remaining actions return the one with the highest score; on a tie, the one that comes first in `actions`.
5. If every action is excluded, return `actions[0].id`.

Do not modify the arguments.

Rules: no Math.random, no Date.now, no new dependencies, no Node APIs, `import type` for types.
Tests: tests/S02-05.test.ts (do not edit).
Done when: vitest, tsc and eslint pass with no errors.

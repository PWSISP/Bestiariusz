# S06-04a — juice: effects of animation cues and their settings

File to edit: src/view/juice.ts

Goal: The pure part of the "juice" of the combat screen: which screen shake, flash, floating number and sound an animation cue triggers, whether the player has switched each of them off, and how far the picture moves during a shake. The screen draws, the platform plays the sounds. Nothing here reads a clock, a storage or `Math.random`.

Signatures (do not change; the file already exports the types, `DEFAULT_JUICE`, `SOUND_IDS` and these stubs):
```ts
export function parseJuiceSettings(text: string | null | undefined): JuiceSettings
export function serializeJuiceSettings(settings: JuiceSettings): string
export function juiceForCue(cue: Cue, settings: JuiceSettings): JuiceCue
export function shakeOffset(strength: number, progress: number, maxPx: number): { x: number; y: number }
```
`Cue` is the type of `src/view/animation-plan.ts` (read it: `kind`, `amount`, `detail`, ...).

`parseJuiceSettings(text)`:
- `null`, `undefined`, `''`, text that is not JSON, and JSON that is not an object (a number, a string, `null`, an array) give `DEFAULT_JUICE`.
- For a JSON object each of the four keys `shake`, `flash`, `numbers`, `sound` is taken when its value is a boolean; a missing key or any other value gives `true` for that key. Other keys are ignored. Never throws.

`serializeJuiceSettings(settings)`: `JSON.stringify` of an object with exactly the keys `shake`, `flash`, `numbers`, `sound` in this order (compact, no spaces), e.g. `{"shake":true,"flash":false,"numbers":true,"sound":true}`. `parseJuiceSettings(serializeJuiceSettings(s))` equals `s`.

`juiceForCue(cue, settings)` returns `{ shake, sound, flash, number }`. First compute the effects of the cue with all settings on, by `cue.kind`:
- `'hit'` (`cue.amount` is the damage dealt): shake only when `amount >= 8`, with `strength = Math.min(1, amount / 30)`; sound `'hit_big'` when `amount >= 10`, otherwise `'hit'`; flash true; number true.
- `'hurt'` (damage to the player): shake only when `amount > 0`, with `strength = Math.min(1, amount / 15)`; sound `'hurt'`; flash true; number true.
- `'ritual'`: shake `{ strength: 0.5, durationMs: 400 }`; sound `'ritual'`; flash true; number false.
- `'death'`: shake `{ strength: 0.3, durationMs: 250 }`; sound `'death'`; flash false; number false.
- `'end'`: sound `'win'` when `cue.detail === 'won'`, `'lose'` when `'lost'`, otherwise none; no shake; flash false; number false.
- `'card'`: sound `'card'`. `'summon'`: sound `'summon'`. `'rejected'`: sound `'reject'`. `'effect'`: sound `'effect'` and number true. Everything else about these kinds is none/false.
- `'turn'`, `'attack'`, `'enemy_act'`: nothing (shake null, sound null, flash false, number false).
- Where a shake is computed from a strength (`hit`, `hurt`), `durationMs = Math.round(150 + 250 * strength)`.
Then apply the settings: `settings.shake === false` makes `shake` null; `settings.sound === false` makes `sound` null; `settings.flash === false` makes `flash` false; `settings.numbers === false` makes `number` false. The result always has all four fields. Never changes its arguments.

`shakeOffset(strength, progress, maxPx)`:
- Returns `{ x: 0, y: 0 }` when `strength` is not > 0, `maxPx` is not > 0, `progress` is NaN or `progress >= 1`.
- Otherwise `p = Math.max(0, progress)` and `amplitude = Math.min(1, strength) * maxPx * (1 - p) ** 2`; the result is `{ x: amplitude * Math.sin(p * 40), y: amplitude * 0.5 * Math.cos(p * 31) }`. Add `+ 0` to both numbers so that a result of `-0` becomes `0`.
- Examples: `shakeOffset(1, 0, 10)` = `{ x: 0, y: 5 }`; `shakeOffset(1, 0.1, 10)` ≈ `{ x: -6.1301, y: -4.0465 }`; `shakeOffset(0.5, 0.25, 8)` ≈ `{ x: -1.2240, y: 0.1168 }`; a strength above 1 is the same as 1.

Examples for `juiceForCue` with all settings on: a `'hit'` with `amount` 7 → `{ shake: null, sound: 'hit', flash: true, number: true }`; with 8 → shake `{ strength: 0.2667 (8/30), durationMs: 217 }`, sound `'hit'`; with 10 → sound `'hit_big'`, shake `{ strength: 0.3333, durationMs: 233 }`; with 30 or more → shake `{ strength: 1, durationMs: 400 }`. A `'hurt'` with 3 → shake `{ strength: 0.2, durationMs: 200 }`.

No Math.random, no Date.now, no `new Date()`, no new dependencies, no Node APIs, `import type` for types.

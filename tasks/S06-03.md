# S06-03 — seeds and reward draw of an expedition

File to edit: src/core/run/rewards.ts

Goal: Two pure functions for the expedition (a short run of fights). `deriveSeed` gives every fight and every reward offer its own seed, computed from the one seed of the expedition, so the same expedition seed always plays the same. `drawRewards` picks the cards a player may choose from after a fight. Nothing here reads a clock or `Math.random`.

Signatures (do not change; the file already exports them as stubs):
```ts
export function deriveSeed(seed: number, salt: number): number
export function drawRewards(pool: readonly string[], count: number, rng: Rng): string[]
```

`deriveSeed(seed, salt)`:
- `seed` must be an integer from 0 to 4294967295 and `salt` an integer from 0 to 1000000, otherwise `RangeError` (also for NaN, fractions, strings).
- The result is an integer from 0 to 4294967295 computed with exactly these steps (all in 32-bit unsigned arithmetic):
  1. `h = (seed ^ Math.imul(salt + 1, 0x9e3779b1)) >>> 0`
  2. `h = Math.imul(h ^ (h >>> 16), 0x85ebca6b) >>> 0`
  3. `h = Math.imul(h ^ (h >>> 13), 0xc2b2ae35) >>> 0`
  4. return `(h ^ (h >>> 16)) >>> 0`
- Examples: `deriveSeed(0, 0)` = 301794027; `deriveSeed(1, 0)` = 2980047484; `deriveSeed(0, 1)` = 3140136926; `deriveSeed(20261102, 0)` = 107933772; `deriveSeed(20261102, 1)` = 3705280566; `deriveSeed(4294967295, 7)` = 3610910960.

`drawRewards(pool, count, rng)`:
- `count` must be an integer >= 0, otherwise `RangeError` (checked first, also for an empty pool).
- Take the ids of `pool` without repeats, keeping the order of their first appearance. When `count` is 0 or nothing is left, return `[]` and do not touch `rng`.
- Otherwise shuffle those ids with exactly one call `rng.shuffle(ids)` and return the first `count` of the result (fewer when there are fewer ids). So with `createRng(1)` and the pool `['iskra','piorun','zrodlo','podmuch','skala','ognisko','grom-kruk-smutek','woda-jelen-odwaga']` and count 3 the result is `['podmuch','piorun','grom-kruk-smutek']`.
- The input array is not changed; the result is a new array.
- No Math.random, no Date.now, no `new Date()`, no new dependencies, no Node APIs, `import type` for types.

Edge cases:
- `drawRewards(['a','a','b','b','a','c'], 3, createRng(7))` → `['c','a','b']` (three different ids).
- `drawRewards(['a','b','c'], 5, createRng(7))` → `['c','a','b']` (only three exist).
- `drawRewards([], 3, rng)` → `[]`; `drawRewards(pool, 0, rng)` → `[]`.
- `drawRewards(pool, -1, rng)`, `drawRewards(pool, 1.5, rng)`, `drawRewards(pool, NaN, rng)` → RangeError.

# S04-08 — Content of the result screen

File to edit: src/view/result-view.ts

Goal: after a combat the game shows a result screen: a title ("Victory" / "Defeat"), a line of flavour text chosen by how the combat went, three statistics and a button. This module turns the summary of a finished combat into text references (key + parameters, see `src/view/text.ts`: `text(key, params?)`); the UI translates and draws them. Read `src/core/combat/summary.ts` (`CombatSummary`) and `src/view/text.ts` first.

Signatures (do not change): `LONG_DEFEAT_TURNS`, `ResultStat`, `ResultView` and `buildResultView` in the stub.

Rules (`summary` is a `CombatSummary`):
1. `summary.turns` must be an integer >= 1, `summary.hpMax` an integer >= 1 and `summary.hpLeft` an integer from 0 to `summary.hpMax` (inclusive); otherwise throw a `RangeError`.
2. `outcome` is `summary.outcome`.
3. `title` is `text('result.won.title')` for a win and `text('result.lost.title')` for a defeat.
4. `enemyName` is `text('enemy.' + summary.enemyId + '.name')`.
5. `flavor` for a win depends on the health that is left, as a fraction of `hpMax`: 3/4 or more → `result.won.flavor.high`; 7/20 (0.35) or more but below 3/4 → `result.won.flavor.mid`; below 7/20 → `result.won.flavor.low`. A fraction exactly on a limit counts for the higher band. Compare with whole numbers (`hpLeft * 4 >= hpMax * 3`, `hpLeft * 20 >= hpMax * 7`), not with divisions.
6. `flavor` for a defeat depends on the turns: `LONG_DEFEAT_TURNS` or more → `result.lost.flavor.long`, fewer → `result.lost.flavor.short`. The health left does not matter for a defeat.
7. `stats` always has three entries in this order: `turns` with label `text('result.stat.turns', { turns: summary.turns })`; `hp` with label `text('result.stat.hp', { hp: summary.hpLeft, max: summary.hpMax })`; `ritual` with label `text('result.stat.ritual.yes')` when `summary.ritualUsed` is true and `text('result.stat.ritual.no')` otherwise.
8. `primary` is `{ id: 'continue', label: text('result.continue') }`.
9. Every key used must exist in both `src/i18n/pl.json` and `src/i18n/en.json` (they do; use exactly the keys above) — do not edit the language files.
10. Never modify the summary. Return new objects.

Edge cases:
- `hpMax` 40: `hpLeft` 30 → high, 29 → mid, 14 → mid, 13 → low.
- `hpMax` 100: `hpLeft` 75 → high, 74 → mid, 35 → mid, 34 → low.
- A win with `hpLeft` 0 is allowed: flavour low.
- A defeat with `turns` 19 → short, 20 → long.

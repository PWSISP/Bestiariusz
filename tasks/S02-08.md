# S02-08 — Ritual (Obrzęd) detection

File to edit: src/core/combat/ritual.ts

Goal: decide whether the three circles form a ritual and of which element. Pure function; the reducer calls it every time a creature enters a circle and decides what the ritual does.

Signatures (do not change): `CircleContent` and `detectRitual(circles, usedThisCombat)` in the stub. Parameter names in the stub start with an underscore only because the stub does not use them; use normal names.

`detectRitual(circles, usedThisCombat): ElementId | null`:
- `circles`: array of exactly 3 entries, each `{ element: ElementId }` or `null`. Any other length: throw `RangeError`.
- `usedThisCombat`: elements that are no longer allowed.
Rules:
1. If any circle is empty, return `null`.
2. Wind (`'wiatr'`) is a wildcard: it joins the ritual of any element.
3. Look at the elements of the non-wind creatures: none (all three are wind) means the ritual element is `'wiatr'`; all the same element means that element; two or more different elements mean `null`.
4. If the ritual element is in `usedThisCombat`, return `null`; otherwise return it.

Do not modify the arguments.

Rules: no Math.random, no Date.now, no new dependencies, no Node APIs, `import type` for types.
